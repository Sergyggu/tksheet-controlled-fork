# tksheet controlled fork

[English](README.md) · [Українська](README.uk.md)

Зафиксированный форк [ragardner/tksheet](https://github.com/ragardner/tksheet) на основе **пакета PyPI 7.6.0**, созданный для панели History в Acceleration Kit / Super-GUI.

Расширения универсального движка таблицы:

- Сегментированный текст в ячейке: фиксированная ширина позиций и общая геометрия отрисовки и определения нажатой позиции.
- Локальный `font_style` для ячейки, строки или столбца.
- Локальный `font_family` с защитой Tier-1: семейство применяется лишь тогда, когда Tk выбирает именно его, а высота символа `|` укладывается в текущую глобальную высоту строки текста.

Приоритет: ячейка → строка → столбец → глобальный шрифт. Размер шрифта наследуется от глобальных настроек и масштаба. Если семейство слишком высокое или Tk подменяет его другим, движок возвращается к базовому семейству. Tier-2 с разной локальной высотой строк в этот выпуск не входит.

## Установка и пример

Нужны Python 3.10+ и Tk. Создайте отдельное виртуальное окружение: этот дистрибутив использует то же имя импорта `tksheet`, что и оригинал.

```sh
python -m venv .venv
# Windows: .venv\Scripts\activate
# Linux/macOS: source .venv/bin/activate
python -m pip install .
python examples/typography_demo.py
python tests/test_runtime.py
python tests/run_legacy.py
```

Версия дистрибутива: `7.6.0+controlled.1`. Значение `tksheet.__version__` оставлено `7.6.0`, чтобы сохранить проверенный снимок исходного кода. Для определения версии форка используйте `importlib.metadata.version("tksheet-controlled-fork")` и манифест происхождения.

Дополнительные параметры пока задаются через словари настроек `sheet.MT`. Точные вызовы приведены в примере. Это внутренний API зафиксированной версии, а не новые методы оригинального `Sheet`. Не устанавливайте оригинальный пакет и этот форк в одно окружение.

## Состав репозитория

`tksheet/` содержит полную универсальную библиотеку. `patches/` — полные изменения двух модифицированных файлов относительно оригинального пакета 7.6.0.

`integration/supergui/` сохраняет проверенные адаптер, Typography Lab и подключение к History как справочный код. Подключение к History требует остальных модулей Acceleration Kit и не является самостоятельной программой. Основной пакет эти файлы не импортирует. Расширения форка и интеграционный код распространяются по MIT; уведомления о MIT оригинала и ISC для Lucide сохранены в `LICENSE.txt`.

**В этом выпуске отсутствуют qualification probe, инструмент сравнения шрифтов, каталог, палитры, дизайнерские подборки и PNG-образцы.** Файлы шрифтов не распространяются. Добавление образцов шрифтов — обязательный следующий этап: они существенно облегчают выбор пользователям. План приведён в [ROADMAP.md](ROADMAP.md).

Сохранённые сентябрьские проверки и инструменты живой приёмки шрифтов находятся в `tests/legacy/`. На текущем Windows-хосте прошли 39/39 проверок Tier-1, 20/20 проверок структуры интерфейса Lab, 11/11 проверок подключения History, selftest типографического слоя и три самостоятельных поведенческих теста Tk. Установка в чистое окружение проверена. Полный запуск Lab требует окружающего Kit и отсутствующего каталога; проверка на других платформах ещё не выполнена.
