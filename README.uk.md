# tksheet controlled fork

[English](README.md) · [Русский](README.ru.md)

Зафіксований форк [ragardner/tksheet](https://github.com/ragardner/tksheet) на основі **пакета PyPI 7.6.0**, створений для панелі History в Acceleration Kit / Super-GUI.

Розширення універсального рушія таблиці:

- Сегментований текст у клітинці: фіксована ширина позицій і спільна геометрія відображення та визначення натиснутої позиції.
- Локальний `font_style` для клітинки, рядка або стовпця.
- Локальний `font_family` із захистом Tier-1: сімейство застосовується лише тоді, коли Tk вибирає саме його, а висота символу `|` вкладається в поточну глобальну висоту рядка тексту.

Пріоритет: клітинка → рядок → стовпець → глобальний шрифт. Розмір шрифту успадковується від глобальних налаштувань і масштабу. Якщо сімейство завелике або Tk підміняє його іншим, рушій повертається до базового сімейства. Tier-2 із різною локальною висотою рядків у цей випуск не входить.

## Встановлення й приклад

Потрібні Python 3.10+ та Tk. Створіть окреме віртуальне середовище: цей дистрибутив використовує те саме ім'я імпорту `tksheet`, що й оригінал.

```sh
python -m venv .venv
# Windows: .venv\Scripts\activate
# Linux/macOS: source .venv/bin/activate
python -m pip install .
python examples/typography_demo.py
python tests/test_runtime.py
python tests/run_legacy.py
```

Версія дистрибутива: `7.6.0+controlled.1`. Значення `tksheet.__version__` залишено `7.6.0`, щоб зберегти перевірений знімок вихідного коду. Для визначення версії форка використовуйте `importlib.metadata.version("tksheet-controlled-fork")` та маніфест походження.

Додаткові параметри наразі задаються через словники налаштувань `sheet.MT`. Точні виклики наведено у прикладі. Це внутрішній API зафіксованої версії, а не нові методи оригінального `Sheet`. Не встановлюйте оригінальний пакет і цей форк в одне середовище.

## Склад репозиторію

`tksheet/` містить повну універсальну бібліотеку. `patches/` — повні зміни двох модифікованих файлів відносно оригінального пакета 7.6.0.

`integration/supergui/` зберігає перевірені адаптер, Typography Lab та підключення до History як довідковий код. Підключення до History потребує інших модулів Acceleration Kit і не є самостійною програмою. Основний пакет ці файли не імпортує. Розширення форка й інтеграційний код поширюються за MIT; повідомлення про MIT оригіналу та ISC для Lucide збережено в `LICENSE.txt`.

**У цьому випуску немає qualification probe, порівнювача шрифтів, каталогу, палітр, дизайнерських добірок та PNG-зразків.** Файли шрифтів не поширюються. Додавання зразків шрифтів — обов'язковий наступний етап: вони суттєво полегшують вибір користувачам. План наведено в [ROADMAP.md](ROADMAP.md).

Збережені вересневі перевірки та інструменти живого приймання шрифтів розміщено в `tests/legacy/`. На поточному Windows-хості пройшли 39/39 перевірок Tier-1, 20/20 перевірок структури інтерфейсу Lab, 11/11 перевірок підключення History, selftest типографічного шару та три самостійні поведінкові тести Tk. Встановлення в чисте середовище перевірено. Повний запуск Lab потребує навколишнього Kit і відсутнього каталогу; перевірку на інших платформах ще не виконано.
