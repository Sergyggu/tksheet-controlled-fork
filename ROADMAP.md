# Roadmap

## Required next publication: font specimens

Font specimens are a required follow-up, deferred by the project owner until after the first source publication. They make font selection substantially easier for users.

- Recover the qualification probe, interactive comparator and selected frozen PNG sheets.
- Include specimen index, sample text, font family/style/size and host/Tk/scaling provenance.
- Label snapshots as visual references, with the live runtime guard remaining authoritative.
- Recover catalogue and designer-pick evidence separately from the renderer.
- Review redistribution permissions for specimen assets; font binaries require their own licences.

This first release does not claim to include these assets.
